Why it exists

Email is bigger than Gmail and Outlook.

Any mailbox

Designed for personal domains, cPanel mail, Fastmail, Zoho, self-hosted Dovecot, and other IMAP-compatible accounts.

Read-first safety

The free version focuses on folder listing, message search, message reading, and attachment metadata without send permissions.

Credential choice

Use local keychain storage by default, or resolve secrets from 1Password or environment variables for multi-machine workflows.

Built for trust

Sending should be deliberate.

The plugin starts read-only because email actions carry real risk. Paid sending will use explicit confirmation, visible recipient and body review, and account identity checks before any SMTP action.

Setup

Configure from the plugin page.

  1. Install IMAP Mailboxes from the Personal plugin marketplace.
  2. Click Try now and run /imap-configure. You can also ask Codex: Open the IMAP plugin setup page.
  3. Add your IMAP host, port, username, TLS setting, and credential provider.
  4. Use Test connection before saving the mailbox profile.
