Mail Actions

Send, reply, update flags, color messages when supported, move, copy, delete, append, and manage folders after entitlement is active.

Setup and billing

Open the setup page with /imap-configure, test before saving, check subscription status, and activate paid access with a Stripe subscription ID.

Setup

Configure from the hosted setup page.

  1. Install IMAP Mailboxes from the plugin marketplace after review approval.
  2. Click Try now and run /imap-configure. You can also ask Codex: Open the IMAP plugin setup page.
  3. Add your IMAP host, port, username, TLS setting, and SMTP settings if you plan to use Mail Actions.
  4. Use Test connection before saving the mailbox profile.
  5. For Mail Actions, subscribe, give the Stripe subscription ID to Codex, then enable SMTP actions in the setup page.
  6. For SMTP checks, use Round-trip to send only to that account's mailbox address, verify the message in its INBOX, and mark it read.
