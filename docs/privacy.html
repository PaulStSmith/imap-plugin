Privacy

Privacy Policy

IMAP Mailboxes is designed around local-first mailbox access.

Mailbox credentials

V1 stores mailbox passwords in the operating system credential store, such as Windows Credential Manager or macOS Keychain. Account profile files do not store raw passwords.

Email content

The plugin reads mailbox content only when you ask Codex to use a configured account. The plugin should not log mailbox passwords or message bodies.

Hosted services

The current plugin does not operate a hosted mailbox sync service. If hosted features are added later, this policy will be updated before those features are released.

Contact

For now, privacy questions can be handled through the plugin distribution channel where you received access.
