Privacy

Privacy Policy

IMAP Mailboxes is designed around local-first mailbox access for Codex.

Current platform scope

IMAP Mailboxes is currently a Codex-exclusive plugin. It is not currently offered as a general ChatGPT GPT, Claude integration, hosted mailbox service, or shared remote MCP service.

Support for other assistant platforms, including Claude, may be considered later if technically and commercially appropriate, but it is not part of the current roadmap.

Mailbox credentials

V1 stores mailbox passwords safely in the local operating system keychain. On Windows, this means Windows Credential Manager. On macOS, this means macOS Keychain. Account profile files do not store raw passwords.

The plugin keeps credential storage on the user's computer through the local keychain provider. Environment-variable and 1Password-backed accounts can be configured for development or advanced workflows, but the default setup page uses local keychain storage.

Email content

The plugin reads mailbox content only when you ask Codex to use a configured account. The plugin does not log mailbox passwords or message bodies.

Hosted services

The current plugin does not operate a hosted mailbox sync service. If hosted features are added later, this policy will be updated before those features are released.

Contact

For now, privacy questions can be handled through the plugin distribution channel where you received access.
