Privacy

Privacy Policy

IMAP Mailboxes is designed around explicit mailbox access for OpenAI surfaces that support remote MCP tools.

Current platform scope

IMAP Mailboxes is a hosted MCP plugin for Codex and compatible GPTs. Claude, Gemini, and other non-OpenAI assistant systems are outside the project scope; any use there is at your own risk.

Support for other assistant platforms may be considered later if technically and commercially appropriate, but it is not part of the current roadmap.

Mailbox credentials

Account metadata is stored separately from mailbox credentials. Hosted public installs may store mailbox credentials behind server-side credential boundaries; local stdio installs can still use the operating system keychain for local-only testing.

ByteForge personnel do not have access to user mailbox credentials in any usable shape or form. Operational access is designed around configuration and diagnostics, not reading passwords or private email.

Environment-variable and 1Password-backed accounts can be configured for development or advanced workflows. Raw mailbox passwords should not be pasted into chat.

Email content

The plugin reads mailbox content only when you ask Codex to use a configured account. The plugin does not log mailbox passwords or message bodies.

Hosted services

The hosted MCP endpoint does not operate a background mailbox sync service. It reads mailbox content only when Codex or a compatible GPT invokes plugin tools for a configured account.

Contact

For now, privacy questions can be handled through the plugin distribution channel where you received access.
