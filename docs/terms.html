Terms of Service

IMAP Mailboxes Beta is a hosted MCP plugin for Codex and compatible GPTs. The hosted MCP server is live and the marketplace listing is under review. These terms describe the intended use while the plugin is being developed and tested. Claude, Gemini, and other non-OpenAI assistant systems are outside the project scope; any use there is at your own risk.

Use of the plugin

You are responsible for the mailbox accounts you connect and for complying with your email provider's terms. Prefer app passwords when your provider supports them.

Read-only v1

The free v1 surface is designed for read access: account setup, folder listing, search, message reading, attachment access, folder status, and quota checks.

Mail actions

Mail actions, including SMTP send and mailbox state changes, require an entitled IMAP Mailboxes installation and enabled plugin preferences. Review requested recipients, message bodies, target folders, and destructive actions before approving them.

Monthly and annual Mail Actions plans are recurring Stripe subscriptions. Founder Lifetime is a one-time Stripe payment that unlocks Mail Actions for the associated installation for the lifetime of this beta/product, subject to fair use, abuse controls, provider limitations, and continued availability of the service.

Credentials and content

Mailbox credentials may be stored behind hosted server-side credential boundaries. ByteForge personnel do not have access to user mailbox credentials in any usable shape or form. The plugin reads mailbox content only when requested through a configured tool call.
